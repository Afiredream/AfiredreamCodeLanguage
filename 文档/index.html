燃梦中文语言

一套用中文书写全部代码的编程语言，从词法分析到解释执行均由中文命名实现。

快速开始

变量 文本:名字 = "张三"
变量 数字:年龄 = 18

如果(年龄 >= 18) {
    终端输出("你好，" + 名字 + "，已成年")
} 或者(真) {
    终端输出("你好，" + 名字)
}

保存为 .象 或 .模块 文件后运行：

./运行 我的程序.象      # 运行文件
./运行                  # 不带参数进入交互终端
./运行 -e '终端输出("你好")'  # 直接执行一段代码

数据类型

类型说明示例
文本字符串"你好"、'单引号'
数字整数或小数42、3.14、-5
状态真或假真、假
数组元素必须同类型[1, 2, 3]、["甲", "乙"]
列表元素可以是任意类型[1, "甲", 真]
对象键值对{名称: "张三", 年龄: 18}
任意不限制类型用于参数标注
空白不限制类型用于参数标注
数组与列表的区别：声明为 数组 类型时，所有元素必须是同一类型， [1, "甲"] 会报错；声明为 列表 则允许混装。

语言里的位置统一从 1 开始数：文本[1] 取第一个字符，数组[1] 取第一个元素。

控制流程

如果

如果(分数 >= 90) {
    终端输出("优秀")
} 或者(分数 >= 60) {
    终端输出("及格")
}

短路语句（单行条件执行）

条件成立就执行后面的动作，动作可以是 返回、赋值或自增：

导出 状态:空白(数组:内容) {
    长短(内容) == 0 && 返回 真     # 为空则返回真
    返回 假
}

数值 > 结果 && 结果 = 数值        # 条件成立才赋值
计数 < 5 && 计数++              # 条件成立才自增

循环

变量 数字:序号 = 1
循环(序号 <= 10) {
    终端输出(序号)
    序号++
}

函数

函数 文本:问候(文本:谁) {
    返回 "你好，" + 谁
}

导出 数字:求和(数字:首个, 数字:其余...) {
    # 其余... 把后面的实参全部收进一个数组
    返回 首个
}

参数默认值

导出 数字:自增(数字:数值, 数字:步长 = 1) {
    返回 数值 + 步长
}

自增(5)      # → 6，省略步长用默认值 1
自增(5, 3)   # → 8

匿名函数

匿名函数只能写在参数位置，形式为 (参数) { 代码 }：

数组.遍历([1, 2, 3], (项, 序号) {
    终端输出("第", 序号, "项：", 项)
})

数组.映射([1, 2, 3], (项, 序号) {
    返回 项 * 10
})   # → [10, 20, 30]

模块

模块文件的后缀名是 .模块。导入时用「模块名.函数」访问，也可以起别名。

导入 ./模块/文本 命名 文本     # 起别名，用 文本.函数(...)
导入 模块/数组                # 不起别名，用 数组.函数(...)
导入 模块/数学 选择 最大值    # 只导入指定函数，可直接用 最大值(...)

文本.切割("测试文本一段长", 1, 2)   # → 测试

导出函数

# 方式一：定义时直接导出
导出 文本:拼接(文本:参数...) {
    返回 "".join(参数)
}

# 方式二：选中已有函数导出
导出 拼接, 切割
命名空间：函数名与变量名共用同一个命名空间，同名会互相遮蔽。 建议不要让参数名与函数名重名（例如参数叫 长度 会遮蔽同名函数）。

全局常量

名称值说明
操作系统系统名称如 Linux、Windows
正无穷大大于一切数常用于求最大值的初始值
负无穷大小于一切数常用于求最小值的初始值
空白文本""空字符串，作为累加初始值

全局常量不能被重新定义或赋值：

变量 数字:正无穷大 = 1
# → 「正无穷大」是全局常量，不能重新定义

交互终端

不带参数运行 ./运行 会进入交互终端，可以逐行输入代码立即执行，变量在多次输入之间保留。

燃梦> 变量 文本:名字 = "张三"
燃梦> 终端输出("你好，" + 名字)
你好，张三
命令作用
:帮助显示可用命令
:退出退出终端（也可按 Ctrl+D）
:清空清空当前会话的变量与函数
:变量列出已定义的变量
:函数列出已定义的函数
:运行 路径执行一个文件
:调试切换词元与语法树显示
